# Data dictionary

Generated by `scripts/data_dictionary.py` from the dbt documentation (`docs/dbt_docs`): descriptions from the dbt YAML, types from the warehouse. Grain of the star schema: **one completed taxi trip** (`fct_trip`). Metric definitions are in `docs/metric_catalog.md` and summarised at the end.

## Bronze (sources)

### `bronze.taxi_zone_raw`

TLC taxi zone lookup, loaded as text and fully replaced on each run.

| Column | Type | Description |
|---|---|---|
| `locationid` | text | TLC taxi zone id (1 to 265; 264 and 265 are unknown). |
| `borough` | text | Borough of the zone. |
| `zone` | text | Name of the taxi zone. |
| `service_zone` | text | TLC service zone (Yellow Zone, Boro Zone, Airports, EWR). |
| `batch_id` | uuid | Ingestion batch that loaded the row (ops.ingestion_manifest). |
| `source_file` | text | Name of the monthly Parquet file the row comes from. |
| `ingested_at` | timestamp with time zone | Time the row was loaded into bronze. |

### `ops.ingestion_manifest`

One row per ingestion attempt, with status, checksums and row counts.

| Column | Type | Description |
|---|---|---|
| `batch_id` | uuid | Ingestion batch that loaded the row (ops.ingestion_manifest). |
| `dataset` | text | Source dataset (yellow trips or taxi zones). |
| `source_month` | date | First day of the month of the source file. |
| `source_url` | text | URL the file was downloaded from. |
| `object_key` | text | Path of the file in the landing zone (raw/yellow/year=YYYY/month=MM/). |
| `source_etag` | text | ETag of the source file (detects a changed file). |
| `file_size_bytes` | bigint | Size of the downloaded file in bytes. |
| `sha256` | text | SHA-256 checksum of the downloaded file. |
| `schema_version` | text | Version of the source contract applied (v2024 or v2025). |
| `schema_hash` | text | SHA-256 of the file's sorted column names and types (schema drift detection). |
| `drift_report` | jsonb | Columns added, missing or of another type than the contract expects. |
| `row_count_file` | bigint | Rows in the Parquet file. |
| `row_count_bronze` | bigint | Rows loaded into bronze (must equal the file). |
| `status` | text | pending, landed, loaded, failed or skipped_unchanged. |
| `forced` | boolean | True when the load was forced although the file had not changed. |
| `error_message` | text | Error of a failed attempt. |
| `started_at` | timestamp with time zone | Timestamp. |
| `finished_at` | timestamp with time zone | Timestamp. |
